状态依次为 designed → fixture-ready → calibrating → ready。目录数量、占位文件、参考 PASS 或脚本演练总分都不能独立证明发布完成。

## 发布门槛

1. 题面与公开/隐藏检查一致，五个功能分组有实际证据，参考可用分为 50/50。
2. 起始缺陷被预声明检查检出，参考与不同结构替代通过，交错/种子可重放。
3. 容器实际执行，网络、资源和进程回收验证；Windows 专项分开报告。
4. 候选、输出、静态事实、性能配对、两轮评审及人工修订对应同一作答。
5. 性能/静态量表经代表性实现校准，四级难度有真实作答样本支持。
6. 集成副本的提交、依赖、许可、哈希可复核；不声称已跑完整来源产品测试。
7. 完整/部分成绩、预览、本机与演练明确区分；缺测不重分配权重，不隐式挑最佳尝试。

验收：pnpm check、pnpm test:e2e、pnpm task:verify <ID>、pnpm trial --all、pnpm score:rehearse。容器可用后运行 pnpm container:build、pnpm container:trial --all。原始证据在 data/，结论在 docs/trials/，设计决定按 Agent Notes 记录。
