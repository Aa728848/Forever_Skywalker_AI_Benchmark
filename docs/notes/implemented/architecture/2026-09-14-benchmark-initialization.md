# Agent Note: 全栈工程评测方案与项目初始化

Status: implemented

## Problem

用户需要基于七个现有项目设计覆盖前端、LSP、后端、缓存、并发、线程、递归、生命周期与性能的四级测试集，并将可用验证和代码质量各设为 50%。原始工作区只有空 Git 仓库，需要先明确任务使用方式、取材范围、评分机制、架构与执行记录，再初始化工程。

## Decision

已完成两轮关键需求澄清和一轮整体方案确认。用户选择独立任务仓库提交、真实场景提炼加少量原仓库集成、自动测量结合独立 AI 评审、Windows 开发与 Linux 正式容器、CLI 配合中文查看面板。

本次交付了：

- 七个来源项目的固定提交、源码证据路径与许可标注；未改动来源项目。
- 48 道核心题及 7 道集成题的结构化设计，每题有公开不变量、检查计划和判定依据；Markdown 从元数据生成。
- 需求、架构、评分、来源、执行记录、阶段验收文档与六类 Agent Note 机制。
- TypeScript/Node 的 CLI、Fastify API、React/Vite 中文面板与独立协议、目录、评分包。
- 50/50 计算、四维质量权重、关键项门槛、缺失/基础设施错误待定、证据引用检查和四级汇总。
- SQLite 评分预览持久化与明确的预览标记。示例 85 分来自公开假设输入，不是任何 AI 的真实测试成绩。

SQLite 第三方原生驱动安装因缺少 C++ 工具链失败，已移除该依赖，采用本机验证可用的 `node:sqlite`，将驱动使用集中到存储模块。浏览器通过项目专属安装脚本和固定 Playwright 版本下载，缓存被 Git 忽略。

## Alternatives considered

- 全部直接基于巨大原仓库出题：用户选择先提炼独立场景，同时保留七道集成题，以控制依赖和复现成本。
- 纯静态分或单一模型总分：不够覆盖运行正确性及人工维护质量，选择固定客观/评审比例与证据引用。
- 把两个 verifier 实现当成严格等价：源代码明确存在去重与聚合变体差异，改为逐题冻结契约和黄金结果。
- 多服务和独立缓存集群：当前本地初始化没有必要，选择小型 workspace 与单进程 SQLite 元数据。
- 安装系统 C++ 工具链以构建 SQLite 驱动：超出必要初始化范围；内置模块可以满足当前预览存储，实验性状态已记录。
- 静默将全部设计题标为可运行：未采用。所有题保持 designed，正式执行器与模型裁判明确列为后续阶段。

## Consequences

用户可以通过 CLI 查看题目、计算输入证据，通过面板筛选题目并保存和复核示例预览。协议与评分核心不依赖浏览器、宿主运行框架或模型供应商。

正式运行仍需要制作夹具、基线与参考补丁、容器执行、快照认证、完成事件、性能校准和独立裁判。M0 无法证明外部输入证据真实，也没有连接模型或消耗模型调用费用。Node 24 的 SQLite 接口为实验性，正式发布前需按锁定补丁版本验证。

## Verification

本机：Windows，Node 24.14.1，pnpm 11.24.0。验证结果：

| 检查 | 实际结果 |
| --- | --- |
| `pnpm typecheck` | 通过 |
| `pnpm catalog:check` | 55 道题协议、唯一性、四级覆盖及 Markdown 一致性通过 |
| `pnpm test` | 2 个文件、20 项测试通过 |
| `pnpm build` | Vite 生产构建通过 |
| `pnpm bench list` / `show CACHE-01` | 目录与题目详情可读取 |
| `pnpm bench score examples/assessment.json --format markdown` | 返回示例可用 45、代码 40、总分 85，标明预览 |
| `pnpm browsers:install` | 固定 Chromium/Headless Shell 1243 安装成功 |
| `pnpm test:e2e` | 1 项浏览器端到端测试通过 |
| 桌面/窄屏截图 | 已检查，无横向溢出；预览及待实现说明可见 |

端到端流程覆盖题目筛选、报告保存、刷新后读取、四条示例证据和窄屏布局。SQLite 在 API 测试中完成关闭后重新打开的数据一致性验证。

最初浏览器缺失引发启动失败；安装后重新运行通过。Windows 沙盒内对测试子进程的清理权限不足，核对本任务进程后结束残留，再在完整进程权限下运行本任务测试；最终测试正常退出。最终结果没有把这次环境失败计作产品成功或候选失败。

没有运行七个来源仓库的完整测试、Linux 正式容器或真实模型裁判；没有执行任何真实交易。
