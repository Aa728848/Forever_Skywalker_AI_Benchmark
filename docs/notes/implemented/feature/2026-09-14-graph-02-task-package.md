# Agent Note: GRAPH-02 题目包（图去重、环与确定性排序）

Status: implemented

## Problem

拓扑排序最容易出的问题不是“算不出来”，而是**结果不稳定**：
重复边被重复计入度、候选节点按输入顺序取，于是同一张图在不同输入排列下给出不同答案，
重复边甚至会让入度永远降不到 0，表现成“误报有环”。

## Decision

- 冻结 `topologicalOrder(nodes, edges)` 与 `CycleError`/`UnknownNodeError`。
- 缺陷族只有一条：**没有规范化输入与输出**（边不去重、后继与起始层都不排序）。
  环检测与未知节点错误在起始版本里就是对的，因此每阶段只失败“确定性”一项检查。
- 参考实现：边去重后 `list.sort()`、起始层 `sort()`、新的零入度节点用有序插入；环路径用染色 DFS 在剩余子图上找。
- 替代实现结构不同：不维护 ready 队列，每轮从剩余节点里线性挑出最小的零入度节点。

## Alternatives considered

- 用输入顺序 + 稳定插入：无法给出“与输入顺序无关”的保证，而确定性正是本题考点。
- 把 `deduplicates-repeated-edges` 做成检出项：实测它在起始版本上通过（三条重复边会把入度恰好降回 0），
  因此它不是这一缺陷的证据，保留为回归护栏而不硬塞进声明。

## Consequences

- 中等档 7/12；核心题 22/48。
- “结果与输入顺序无关”这类契约必须在检查里**显式换序重跑**才能验证，这也是本题隐藏检查的重点。
