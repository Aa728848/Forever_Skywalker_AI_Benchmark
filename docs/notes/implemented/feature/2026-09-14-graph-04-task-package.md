# Agent Note: GRAPH-04 题目包（循环依赖图的增量失效与全量等价）

Status: implemented

## Problem

增量失效是前端状态管理的核心机制：某个节点变化后，所有直接或间接依赖它的节点都必须重算。
只失效直接依赖者的实现会漏掉传递依赖与环内节点，界面继续展示过期数据，而且**很难被发现**——
它只在依赖链超过一跳时才出错。

## Decision

- 冻结 `Invalidator.invalidate` 与 `UnknownNodeError`。
- 缺陷族只有一条：**只传播一跳**（间接依赖与环内其它节点漏掉）。
- 参考实现用广度优先传播 + 已访问集合（入队即标记，环自然终止）；
  替代实现用递归深度优先 + 已访问集合（结构不同）。
- 检查内置**朴素全量可达性**（每个 changed 做一次 DFS 再取并集）作为独立对拍基准，
  而不是把期望集合写死——这样期望值随输入图变化自动成立，也避免把实现细节固化进断言。

## Alternatives considered

- 把期望集合逐条写死：图一改就要重算期望值，容易写成“抄实现”；改为与朴素算法对拍。
- 用拓扑排序实现：有环时拓扑排序本身不成立，而本题明确要求环内收敛，因此不用。

## Consequences

- 极度困难档 3/12；核心题 34/48。
- 与 GRAPH-01（遍历终止与叶节点）、GRAPH-02（去重与确定性排序）、GRAPH-03（PR 图）形成图算法簇，
  四道题共享同一套“确定性 + 对拍”的验证范式。
