# Agent Note: 补齐开发交接与执行手册

Status: implemented

## Problem

初始化提供了方案、路线图和运行记录规范，但缺少一份明确告诉下一位执行者从哪里开始、按什么依赖顺序实施以及如何交付证据的独立交接文档。用户指出了这一缺口。

## Decision

新增 `docs/handoff.md`，记录 M0 当前能力与代码入口、已确认约束、M1-01 至 M1-06 执行队列、CACHE-02 首道任务、其余七道试点、已知环境问题、验收与再次交接模板，以及可直接交给 AI 的执行指令。

README、AGENTS.md 和 roadmap 增加接手链接。保持既有题库、评分与阶段范围；本次仅补文档，没有启动 M1 开发。

## Alternatives considered

- 仅引用 roadmap：路线图已有阶段目标，但缺少代码入口、可执行先后关系和已知实现限制，不能替代此次交接要求。
- 再写一份完整需求文档：会重复已确认规格，增加漂移；交接文档引用原规格，只拥有执行顺序与交接状态。
- 直接开始制作任务：本次请求是补交接资料，先交付可供执行的文档，保持当前范围。

## Consequences

下一位可以从 CACHE-02 明确开始，并识别 preview-only 协议、55 题目录检查、容器与裁判缺口。历史 20 项单元/API 测试和 1 项浏览器测试标注为 M0 已有证据，不冒充本次新跑结果。

后续阶段完成时需要同步交接状态与 roadmap，但评分与题目规格仍在各自文件维护。
