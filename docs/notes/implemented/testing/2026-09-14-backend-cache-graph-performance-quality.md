# Agent Note: 后端、缓存、图与性能九题的工程鉴别力提升

Status: implemented

## Problem

用户要求全面审查现有题库，并改善不足以区分真实工程开发能力的题目。本批审查 API/CACHE/GRAPH/PERF 共 16 题：保留 API-03/04、CACHE-01/02、GRAPH-01/04、PERF-02 的能力范围，升级其余九题。发现的问题包括公开/隐藏样本重复、循环路径只检首尾、错误 oracle 调用被测解析器，以及部分高难题只靠数据规模或一次局部 guard。

## Decision

| 题目 | 新版本 | 改进 |
| --- | --- | --- |
| API-01 | 0.2.0 | 明确普通对象原型边界，独立组合验证全部错误与排序，修复正确实现原型/排序缺口 |
| API-02 | 0.2.0 | 编解码统一非负安全整数契约，拒绝非规范 base64url 字节，独立分页划分 oracle |
| CACHE-03 | 0.2.0 | 多键一致读取、当前代错误重试、旧代失败不清理新在途，三个近似错误修复 |
| CACHE-04 | 0.2.0 | 多键原子持久化、刷新/查询队列切面、真实文件同步/替换与子进程中断，三个近似错误修复 |
| GRAPH-02 | 0.2.0 | 修正自环契约，验证每条闭环边及多环排列稳定性，独立 DAG 排序 oracle |
| GRAPH-03 | 0.2.0 | 共享 AST 转换、子树结果传播、增量身份复用、全树预检和回调失败，三个近似错误修复 |
| PERF-01 | 0.2.0 | 修复合法原型键数据丢失，独立累计 oracle 不调用候选解析器 |
| PERF-03 | 0.2.0 | 增量图统计事务、缺失目标恢复、独立连续编辑 oracle，三个反例及新增主路径性能负载 |
| PERF-04 | 0.3.0 | 有界流式会话投影、生命周期重开、检查点身份、持久确认和代际隔离，四个反例及更新后的主路径性能负载 |

保留旧公开接口与必要回归，测试预先声明新失败目标。新增 CACHE-04/PERF-04 场景依据固定 deepseek-harness 提交的持久优先写入链、完整投影切面与日志生命周期身份机制，文件清单位于题目受信侧 source-evidence.json；原项目没有修改。

## Alternatives considered

- 仅增大节点/日志规模：无法检验持久确认、跨代竞争及局部更新的正确性，因此没有把规模作为主要难度来源。
- 将所有题都改为极难：会丢失基础与中等能力定位；保留七道适合原级别的题目能力范围。
- 为新检查放宽失败集合：不采用。首次作者工具错误、起始缺陷互相抵消和无关前置条件的失败均保留记录；修复作者工具或隔离前置条件，而不根据观察结果追加检出目标。

## Consequences

九题仍是 fixture-ready，未调用真实模型，不把三向或反例检出率解释为真实模型通过率。新版本不能与旧版本混合汇总。参考与结构不同的替代实现都需通过，所有缺失、崩溃及额外交叉断言原样记录。

PERF-03/04 性能负载直接执行新索引/流式投影主路径，不能用旧纯函数的微基准替代新系统性能证据；内部计时与 RSS 只用于诊断，正式比较使用平台外部计时和固定容器配对，阈值保持未校准。
