# Agent Note: 裁判与Web集成题的部分修复检出审查

Status: implemented

## Problem

用户要求题目能够区分实际工程水平。原集成题虽然已有真实模块链和起始缺陷对照，还缺少“只修对一半”的错误方案验证。INT-WEB原检查仅同时持有一个SSH别名，无法拒绝释放所有别名连接的过度清理实现。

## Decision

- INT-VERIFIER保留0.1.0设计与11个检查，新增3个参考实现上的近似错误修复：包含模型/候选但漏规则上下文的缓存身份；网络合并正确但重复计费；后续成功编辑会使验收过期但失败写入不会。
- INT-WEB验证版升0.2.0，保留固定源码、参考/替代与所有许可证和哈希。新增13项中的跨别名资源检查：目标别名持有两个隧道，另一别名有独立监听；删除目标后其两个隧道释放，另一别名的监听、连接和池记录仍有效，通过真实startTunnel入口继续复用。
- INT-WEB新增4个近似错误修复：仅在一个apply闭包内去重；失败只报告而不回滚真实文件；停止所有别名；只停止首个兄弟隧道。目标在运行之前声明，保留交叉失败，不根据输出反向改目标。

## Alternatives considered

不把恢复某个明显错误常数当成全部反例，也不为制造难度重写真实模块。INT-VERIFIER已有足够断言拦住选定部分修复，因此仅增加受信反例证据，不提升行为版本。INT-WEB增加真实资源归属边界，不缩减为mock计数。

## Consequences

两个集成设计都保留，INT-WEB的验证缺口已补。完整源码仍来自其source-provenance.json所列固定提交；修改不进入来源仓库，不执行真实模型、真实SSH配置或外网调用。该证据说明选定近似错误能被检出，仍不代表真实模型解题率已经校准。
