# v0.1.0-preview.1

Forever Skywalker AI Benchmark 首个 GitHub 预览版本：用可复现工程任务比较 AI 开发能力，并按可用验证与代码质量各 50% 评分。

## 本版内容

- 55 道真实题目包：48 道核心题覆盖 12 个领域与四个难度，7 道固定来源模块集成题单独报告。
- CLI、中文 Web 面板、候选冻结、Linux 容器验证、静态分析、性能配对、两轮独立裁判及人工复核。
- 8 个裁判供应商的协议与推理参数；`.env` 可设置裁判思考等级。
- DSH 标准、PTC、极简、创造四种原始预设，独立指定作答模型、思考等级、题单和重复数。
- DSH 自动分发、作答、验证与报告；报告及压缩证据保存校验后清理本次独占临时数据。
- 来源许可、任务契约、评分标准、交接手册和中文 Agent Notes。

## 使用入口

需要 Node 24.14.1 与 pnpm 11.24.0；固定 Linux 评分环境按 `docs/container-setup.md` 配置。复制 `.env.example` 为 `.env`，填写自己的配置。运行 `pnpm dev` 打开中文面板；DSH 自动比较见 `docs/dsh-comparison.md`，裁判参数见 `docs/judge-providers.md`。

本版发布源码与题目资产，不包含 `.env`、私有凭据、模型作答记录或本机 Docker 镜像。DSH 自动化需要另行准备同版本 SDK/CLI 构建与自己的供应商配置。

## 验证与状态

本地 `pnpm check` 的 198 项回归、类型检查、55题目录一致性和 Web 构建通过。固定 Linux 镜像已完成 55 题参考/替代/缺陷验证；真实 DSH SDK 对本地假模型的四预设验收通过。详情及历次验收范围见 `docs/handoff.md`。

这是预览版本。真实模型与独立裁判试跑、静态/性能阈值以及难度校准尚未完成；题目保持 `fixture-ready`，缺证据的分数保持待定，不能作为已校准的正式排行榜成绩。
